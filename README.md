# hlpatch-reasoning-log

推理过程存档。

**这里只放「怎么想的」，不放数据。** 数值、地址表、偏移常量另存，不混进本仓。

---

## 为什么单独开一个仓

数据可以重抓，判断过程不能重放。出问题时真正要复盘的是：

- 当时为什么停在这里
- 哪一步是猜的、哪一步是验的
- 假设在哪个点被推翻、推翻后改成了什么

把这些和数据混在一起，等于两边都看不清。

---

## 收录规则

| 收 | 不收 |
|:--|:--|
| 判断分支、试错、死路 | 具体数值表 |
| 假设与它的证伪方式 | 内存地址清单 |
| 自我核对的方法论 | 偏移常量 |
| 未解决问题的清单 | 端点输出原文 |
